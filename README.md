\# Real Estate Portal



A six-member coursework project using Java, Spring Boot,

Maven, MySQL and React.



\## Member responsibilities



1\. User and Access Management

2\. Property Listing Management

3\. Moving Service Directory Management

4\. Viewing Appointment Management

5\. Offer Management

6\. Review and Feedback Management



\## Project folders



\- backend: Java and Spring Boot application

\- frontend: React screens

\- database: MySQL scripts

\- docs: Setup instructions and test results



\## Team workflow



Each member writes and tests their assigned module.

Members work on separate feature branches.

Pull requests combine reviewed changes into development.

Tested releases are merged into main.



\## Project history



This is a new implementation.

Earlier prepared projects remain separate as references.
